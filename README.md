# North African Genetic Groups Atlas

A mobile-first interactive atlas of North African genetic groups.

## Live site

The project is designed to run directly on GitHub Pages. Open `index.html` locally or visit the Pages URL published with this repository.

## Included data

- 94 groups from the Atlas's **North African** branch
- 12 groups from its **Egyptian & Southern Levantine** branch, all of which are Egyptian groups
- 106 embedded region polygons
- Full group descriptions
- Common maternal and paternal haplogroups
- CSV and JSON exports in [`data/`](data/)

The interface is optimized for phones with dedicated Map and Regions views, large touch targets, search, category filtering, and a bottom-sheet details panel. Country outlines and all group polygons are embedded, so the map does not depend on third-party tile servers.
